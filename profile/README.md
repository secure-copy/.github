# WinSCP - Your Account, Your Folder

## Places

The host name you were given.
The user name that is yours.
A local folder that contains only what you mean to upload.
The remote folder you are supposed to touch, not the top of the server.

## Cue light

Connect.
Read the host key prompt. If you have a fingerprint to compare, compare it. If you have never been given one and the server is new to you, ask before you accept.
Open the remote folder you expect.
Upload or download one small file.

## Sound cue

The small file arrives and opens.
The remote listing matches the names you know.
A second file can wait until the first is right.
You disconnect when the job is done. A session left open is a logged-in computer.

## Hold

Do not save a password on a shared PC.
Do not accept a changed host key because you are in a hurry. That change is the stop.
Do not sync a whole home directory to a server on the first connection.
Do not use someone else's account because they left a shortcut.

## Go

One folder up, one folder down.
Overwrite only when the preview of the name is the file you intend to replace.
If the transfer fails halfway, the partial file is not the file. Send it again.
Then disconnect.

## Strike

A stored site that is no longer yours. Remove it.
A password manager entry you did not mean to save in the app. Remove it from the app.
A sync that deleted remote files. Stop. Restore from the copy that was not in that job, if you have one. Do not run the sync again to "fix" it.
A host key mismatch you clicked through. Disconnect and treat the session as untrusted until the owner explains the new key.

Host name.
Whether the key matched.
The folder.

## Not this show

This does not find servers on a network for you to try.
It does not bypass a login.
A local copy tool moves disks on this PC. This talks to a host you already know.
A cloud sync you did not configure is a different account. Do not mix them in one drag.
Anonymous space on a server you do not run is still not yours to fill.

## Next call

The same site, the same folder.
If the key changed, you heard why before you accept.
A new PC gets the site only if you are willing to check the key again.
Passwords stay out of a shared Windows login.

## House up

Disconnected.
No transfer running.
Stored sites reviewed.
On a PC you are giving away, remove the sites and the saved keys.
Uninstall leaves the local copies you already downloaded. Those files are still your responsibility.

## Dark stage

Connection refused. The host, the port, or the network. Ask the owner. Do not scan for an open door.
Login failed. The password is wrong. Stop guessing on a shared account.
You are in the wrong remote directory. Go up until you recognize it. Do not upload there.
The local pane is a system folder. Change it before you drag.
